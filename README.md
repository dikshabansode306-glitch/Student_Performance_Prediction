# Student Performance Prediction System

This project is a **Supervised Machine Learning** application developed during my internship to predict a student's final grade based on academic and social factors.

## 🚀 Project Overview
The goal of this system is to provide early intervention for students at risk of underperforming. By analyzing variables such as previous grades, study time, and absences, the model predicts the final grade (G3).

## 🛠️ Tech Stack
*   **Language:** Python
*   **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
*   **Environment:** Google Colab

## 📊 Key Analysis
*   **Algorithm:** Linear Regression
*   **Evaluation:** Mean Absolute Error (MAE) and R² Score.
*   **Visualization:** Includes a Correlation Heatmap to show which factors impact grades the most.
